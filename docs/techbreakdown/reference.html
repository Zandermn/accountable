02

Command reference

Run these from the repository root unless stated otherwise.

CommandResultCaution
uv python install 3.12Install the required Python runtime.One-time setup; internet.
uv sync --lockedInstall Python dependencies into .venv/.Uses uv.lock.
npm ciInstall JavaScript dependencies.Uses package-lock.json; internet for first setup.
npm run devStart Uvicorn and Vite.Keep terminal open; Ctrl+C stops.
npm testRun Vitest, pytest, and Playwright.Any failure or startup error gives nonzero exit.
npm run test:uiRun frontend unit tests.Uses jsdom, not full Chrome.
npm run test:apiRun backend tests.Uses temporary databases.
npm run test:e2eRun browser tests.Starts isolated app itself; needs Chrome.
npm run buildType-check and build into frontend/dist/.Does not replace behavior tests.
npm run saveWrite a full JSON backup and print its ID.Safe normal backup operation.
npm run load -- <backup-id>Back up current state, then replace it with the selected backup.Replaces active records and Trash.
npm run seedAfter yes and a backup, replace current data with samples.Replaces active records and Trash. Enter cancels.
git statusShow working tree state.Read-only.
git diffShow unstaged source changes.Read-only.

04

JSON API summary

All paths have the /api prefix. Record kinds are organizations, contacts, deals, and where accepted activities. Write routes expect X-Dataset. Operations with a preview also check a revision or token.

MethodPathPurpose
GET/versionSchema state, dataset ID, and revision.
GET/records/{kind}List with search, sort, direction, and optional status.
POST/records/{kind}Create.
GET/records/{kind}/{id}Detail, links, and applicable timeline.
PATCH/records/{kind}/{id}Edit supplied fields.
GET/records/{kind}/{id}/delete-previewRead blockers and deletion impact.
DELETE/records/{kind}/{id}Soft-delete with preview revision.
GET/trashList deleted records with kind and direction options.
POST/trash/{kind}/{id}Restore with recovery choices when required.
GET/pipelineOrdered columns, cards, revision, and totals.
POST/pipeline/moveChange stage or position with a board revision.
GET/dashboardMonthly results, totals, funnel, activity, and follow-ups.
GET/workbook/templateDownload blank .xlsx template.
GET/workbook/exportDownload active main records.
POST/workbook/previewValidate and preview an uploaded workbook.
POST/workbook/applyApply with file and matching preview token.
GET/backupsList valid app-managed backups.
POST/backups/{id}/confirmStart deletion and issue a backup-bound token.
POST/backups/{id}/cancelCancel that confirmation.
DELETE/backups/{id}Permanently delete after valid confirmation.

Common errors: 404 unavailable resource, 409 current-state conflict, and 422 invalid input. FastAPI's generated /docs and /redoc pages are disabled.
