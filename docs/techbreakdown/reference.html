Command reference

Run these from the repository root unless stated otherwise.

CommandResultCaution or limit
uv python install 3.12Install the required Python runtime.One-time setup; internet.
uv sync --lockedInstall Python dependencies into .venv/.Uses uv.lock.
npm ciInstall JavaScript dependencies and Lefthook hooks.Uses package-lock.json; internet for first setup.
npm run devStart Uvicorn and Vite after API readiness.Keep terminal open; Ctrl+C stops.
npm run formatApply Prettier and Ruff formatting.Does not run lint, types, secrets, or tests.
npm run checkAll static and secret checks, then all three test suites.Required before reporting a code change complete.
npm run check:quickStatic checks, secrets, Vitest, and pytest.Skips Playwright.
npm testRun Vitest, pytest, and Playwright.Any failure or startup error gives nonzero exit.
npm run test:uiRun frontend unit tests and coverage.Uses jsdom, not full Chrome.
npm run test:apiRun backend tests and coverage.Uses temporary databases.
npm run test:e2eRun browser tests.Starts isolated app itself; needs Chrome.
npm run buildType-check and build into frontend/dist/.Does not replace behavior tests.
npm run saveWrite a full sales JSON backup and print its ID.Preserves the app preference separately.
npm run load -- <backup-id>Back up current state, then replace sales and recovery data.Replaces active records and Trash.
npm run seedAfter yes and a backup, replace sales data with samples.Replaces active records and Trash. Enter cancels.
git status / git diffShow working-tree state / unstaged source changes.Read-only; inspect before and after work.

05

JSON API summary

All paths have the /api prefix. Record kinds are organizations, contacts, deals, and where accepted activities. Sales record and board writes expect X-Dataset. Preview-based operations also check a revision or token. Theme preference writes use PUT and do not advance the sales revision.

MethodPathPurpose
GET/versionSchema state, dataset ID, and sales revision.
GET/records/{kind}List with search, sort, direction, and optional status.
POST/records/{kind}Create.
GET/records/{kind}/{id}Detail, links, and applicable timeline.
PATCH/records/{kind}/{id}Edit supplied fields.
GET/records/{kind}/{id}/delete-previewRead blockers and deletion impact.
DELETE/records/{kind}/{id}Soft-delete with preview revision.
GET/trashList deleted records with kind and direction options.
POST/trash/{kind}/{id}Restore with recovery choices when required.
GET/pipelineOrdered columns, cards, revision, and totals.
POST/pipeline/moveChange stage or position with a board revision.
GET/dashboardMonthly results, totals, funnel, activity, and follow-ups.
GET/workbook/templateDownload blank .xlsx template.
GET/workbook/exportDownload active main records.
POST/workbook/previewValidate and preview an uploaded workbook.
POST/workbook/applyApply with file and matching preview token.
GET/backupsList valid app-managed backups.
POST/backups/{id}/confirmStart deletion and issue a backup-bound token.
POST/backups/{id}/cancelCancel that confirmation.
DELETE/backups/{id}Permanently delete after valid confirmation.
GET / PUT/preferences/themeRead or replace the shared light/dark app preference.

Common errors: 404 unavailable resource, 409 current-state conflict, and 422 invalid input. FastAPI's generated /docs and /redoc pages are disabled.

TermPlain meaning

ActiveOutside Trash. Closed Won and Lost deals can still be active.

APIA defined way for programs to communicate.
AssertionA test statement that must be true.
Atomic operationWork that completes as one unit or has no effect.
BackendServer-side code that handles rules and saved data.
BranchA movable Git name for a line of commits.
BuildTransform source into runnable or distributable output.
CIContinuous integration: automated checks run on shared source events such as a push.
Commit (Git)A saved source-history snapshot.
Commit (database)Make a transaction's changes persistent.
ComponentA reusable React function that describes UI.
ConstraintA database-enforced rule for valid rows and links.
CRUDCreate, Read, Update, and Delete.
Dataset revisionAn identifier changed by load or reset so stale views must reload.
Defense in depthSeveral controls whose different limits cover one another.
DependencyExternal code required by the project.
Design tokenA named visual value, such as a theme surface or text color.
DiffA line-by-line comparison of source changes.
DOMThe browser's live object representation of a document.
EndpointA specific API method and path.
Environment variableA named value supplied to a running process.
FixtureReusable test setup and cleanup.
Foreign keyA column that references another table's row.
FrontendThe browser-facing part of an application.
Hash / checksumA fixed-length fingerprint used to detect changed content.
HookA React stateful helper, or an agent/Git event action; context determines which.
HTML / CSSLanguages for page meaning and visual presentation.
HTTPThe web's request-and-response protocol.
InvariantA domain rule that every valid operation must preserve.
JSONA text format for objects, arrays, and simple values.
