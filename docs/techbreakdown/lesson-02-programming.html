Learn the small set of programming ideas used throughout Accountable. Examples use JavaScript and Python, the project's two main languages.

The mystery

Why can the number 25 and the text "25" behave differently? And how can a few simple instructions become a complete CRM?

Why it matters: If you can read values, decisions, functions, and errors, you can predict what the source will do. That is the first step toward changing code safely.

01

Programs, statements, and values

Problem to solve

A user types 25 into a probability field. Is that a number to calculate with or text to display? What would happen if the program confused the two?

The answer: Data types tell the program what a value means and which operations are valid. Statements and expressions use those values to do work.

A program is a sequence of instructions. A statement performs an action. An expression produces a value. A program executes, or runs, those instructions.

A literal is a value written directly in code. These are common data types:

TypeJavaScript / TypeScriptPythonUse
String'New'"New"Text
Number12500, 2.512500, 2.5Counts and amounts
Booleantrue, falseTrue, FalseYes/no state
No valuenull, undefinedNoneMissing or empty value
Case matters: JavaScript uses true. Python uses True. A number and its string form are different: 25 is a number, while "25" is text.

Accountable stores a deal value as an integer number of cents. For example, 12500 means US$125.00. This avoids many decimal rounding problems. It stores probability as a whole percentage from 0 to 100.

02

Variables and operators

Problem to solve

How can the app calculate expected revenue for any deal without writing a separate formula for every value and probability?

The answer: Variables name changing values, while operators perform calculations and comparisons. One formula can then work for every deal.

A variable is a name that refers to a value. Assignment stores or changes that reference. An operator calculates or compares values.

JavaScript
const stage = 'New';
let probability = 10;
probability = 25;

const expected = 10000 * probability / 100;
Python
stage = "New"
probability = 10
probability = 25

expected = 10000 * probability / 100

JavaScript const prevents reassignment of that variable name. let permits reassignment. Python variables can be reassigned by default. Neither example needs a semicolon in Python.

OperationJavaScriptPython
Arithmetic+, -, *, /
Equality comparison=== (strict)==
Greater / less>, <, >=, <=
And / or / not&&, ||, !and, or, not

One = assigns. A comparison such as === or == asks whether values match and produces a boolean.

See backend/services/sales.py. Its totals() function adds value_cents and calculates expected revenue. The extra + 50 before integer division rounds to the nearest cent after all deal values are summed.

03

Collections: group related values

Problem to solve

How can the app display two contacts today and two hundred tomorrow without creating a new variable for every person?

The answer: Arrays hold ordered groups, while objects and dictionaries give names to each record's fields. Transformations process groups of any size.

A list or array stores values in order. An object or dictionary stores named key-value pairs.

JavaScript
const stages = ['New', 'Qualified', 'Won'];
const deal = {
  name: 'Renewal',
  value_cents: 10000,
  probability: 25
};

console.log(stages[0]);      // New
console.log(deal.name);      // Renewal
Python
stages = ["New", "Qualified", "Won"]
deal = {
    "name": "Renewal",
    "value_cents": 10000,
    "probability": 25,
}

print(stages[0])       # New
print(deal["name"])    # Renewal

Indexes start at zero. stages[0] is the first item. JavaScript often accesses an object property with a dot. Python dictionary values commonly use square brackets and a key.

JavaScript arrays have methods such as .map(), .filter(), and .find(). Python has loops and comprehensions. Accountable uses these operations to select visible records, build table cells, and group pipeline cards.

A JavaScript transformation
const names = ['Ada', 'Grace', 'Linus'];
const labels = names.map((name) => 'Contact: ' + name);
// ['Contact: Ada', 'Contact: Grace', 'Contact: Linus']

The arrow => defines a small function. .map() calls it for every item and returns a new array.

04

Conditions and loops

Problem to solve

How can the app reject a deal with no linked owner, accept a valid one, and repeat that check for every row in an import?

The answer: Conditions choose the valid or invalid path. Loops repeat the same logic for every item without duplicated code.

An if statement selects a branch when a condition is true. A loop repeats work for items or until a condition changes.

JavaScript
if (deal.stage === 'Won') {
  console.log('Closed as won');
} else {
  console.log('Not won');
}

for (const stage of stages) {
  console.log(stage);
}
Python
if deal["stage"] == "Won":
    print("Closed as won")
else:
    print("Not won")

for stage in stages:
    print(stage)

JavaScript uses braces { } to group blocks. Python uses indentation. In Python, four spaces are the common indentation width. Do not mix tabs and spaces.

Real examples include:

  • backend/services/records.py checks whether a deal has an organization or main contact.
  • frontend/src/Records.tsx maps each database row to a table row.
  • backend/services/sales.py loops through deals to calculate six monthly chart buckets.
05

Functions, parameters, and modules

Design puzzle

Forms, imports, and commands all need the same record validation. Should every file contain another copy of those rules?

The answer: Functions package reusable operations with named inputs and results. Modules organize those functions so other files can import one shared implementation.

A function is a reusable block of logic. A parameter is an input name in its definition. An argument is the value supplied in a call. return sends a result to the caller.

TypeScript
function money(cents: number): string {
  return 'US$' + (cents / 100).toFixed(2);
}

money(12500); // US$125.00
Python
def money(cents):
    return f"US${cents / 100:.2f}"

money(12500)  # US$125.00

The Python example uses an f-string to insert a value into text. TypeScript annotations such as : number describe expected types. Lesson 4 explains them.

A module is a file that can export code for other files. An import makes that code available. A package or library is reusable code distributed for many projects.

Imports in backend/main.py
from fastapi import FastAPI, Request
from sqlalchemy import select
from backend.api.records import router as record_routes

The first two imports use third-party packages. The third imports this project's own module. Keeping API routes, business rules, and schema in different modules makes each part easier to find and test.

06

Classes and objects

Design puzzle

The app needs to keep a database path, engine, backups folder, and transaction behavior together. Where should that related state and logic live?

The answer: A class defines that bundle. Each object is an instance with its own state and shared methods, such as Accountable's Store.

A class defines a kind of object with data and behavior. An object or instance is one value created from that class. A method is a function attached to an object.

A small Python class
class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1

counter = Counter()
counter.increment()
print(counter.value)  # 1

Accountable's Store class in backend/db/__init__.py owns the database engine, file paths, and read/write transaction methods. The Problem class represents an application error with an HTTP status and response details. You can use the app without knowing class theory. Read a class as a blueprint and an object as the thing built from it.

07

Errors and asynchronous code

Problem to solve

The network is slow or the server rejects a request. Should the whole interface freeze or erase your draft?

The answer: Async code waits without blocking other work. Errors select a recovery path, and finally clears temporary states such as busy.

An exception or runtime error interrupts the normal path. Code can raise an error deliberately when input is invalid. It can catch an error to show a useful message instead of stopping everything.

JavaScript
try {
  await saveDeal();
} catch (error) {
  showMessage(error.message);
} finally {
  setBusy(false);
}
Python
try:
    value = int(text)
except ValueError:
    print("Enter a whole number.")
finally:
    print("Check complete.")

finally runs whether the operation succeeds or fails. The frontend uses it to clear a busy state after a request.

Why some code uses async and await

A network request takes time. Asynchronous code lets a program handle waiting without blocking all other work. JavaScript fetch() returns a Promise: a future result or failure. await pauses that async function until the Promise settles.

Simplified from frontend/src/data.tsx
async function loadContacts() {
  const response = await fetch('/api/records/contacts');
  if (!response.ok) {
    throw new Error('The request failed.');
  }
  return response.json();
}

Do not confuse await with a database commit. Waiting for an HTTP response only says that the server responded. Accountable's backend commits a successful write transaction before it returns success.

A context manager is a related Python pattern. with store.write() as conn: gives the service a connection and commits or rolls back when the block exits. Lesson 5 explains it.

08

Practice and review

Predict the result: A deal has value_cents = 20000 and probability = 50. What is its unrounded expected value in cents?
Answer

20000 * 50 / 100 = 10000 cents, or US$100.00. Accountable sums these products for all open deals before it rounds the total.

1. What is the difference between a function parameter and an argument?

A parameter is the named input in the function definition. An argument is the actual value in one call. In money(cents), cents is a parameter. In money(12500), 12500 is an argument.

2. Why does Accountable use cents instead of a dollar decimal?

Integer cents give exact arithmetic at the storage precision. The workbook code converts decimal dollars to integer cents and rejects amounts with fractions of a cent.

3. What does a module import do?

It lets one file use exported definitions from another file. This supports small modules with clear jobs instead of one large source file.
