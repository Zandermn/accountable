# Sample data

Initialize a new Supabase database with sample data once. Existing records in the local SQLite database stay in that database. An intentionally empty shared database remains empty on startup.

Use fictional, realistic organizations from several industries, contacts in every status, and deals in all six stages. Generate dates relative to the date when the seed runs. Include wins and losses across several past months, late open deals, future closes, notes, calls and emails, and both upcoming and overdue follow-ups. Include coherent stage history for the funnel and enough linked records to try the main workflows. Start with empty Trash.

Show **Sample data** in the [Added by](records.md#attribution) field on seeded records and activities.

Use US Eastern Time for sample follow-ups. Set their due dates relative to the date in that time zone when the seed runs.

## Verification

Check that a new database starts with the sample records and empty Trash. Restart and verify that the sample data does not duplicate or replace saved work. Check the creator label on seeded organizations, contacts, deals, and activities.
